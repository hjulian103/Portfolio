# Portfolio

A modern, responsive portfolio website built with HTML, JavaScript, and Tailwind CSS.

## Features

- 📱 **Fully Responsive**: Works perfectly on desktop, tablet, and mobile devices
- 🎨 **Modern Design**: Clean and professional layout with smooth animations
- 🚀 **Fast Performance**: Optimized JavaScript with throttled scroll events
- 📧 **Contact Form**: Interactive form with validation and success messages
- 🎯 **Smooth Navigation**: Fixed navbar with smooth scrolling to sections
- 📱 **Mobile Menu**: Hamburger menu for easy mobile navigation
- ⚡ **No Dependencies**: Self-contained CSS, no external CDN required

## Sections

1. **Hero**: Eye-catching introduction with call-to-action buttons
2. **About**: Personal introduction and social media links
3. **Skills**: Showcase of technologies and skills
4. **Projects**: Featured projects with descriptions
5. **Contact**: Functional contact form

## Getting Started

Simply open `index.html` in a web browser to view the portfolio.

For development, you can use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server
```

Then navigate to `http://localhost:8000` in your browser.

## Customization

To customize the portfolio for your own use:

1. **Personal Information**: Edit the name and title in `index.html` (search for "Your Name")
2. **About Section**: Update the bio text and social media links
3. **Skills**: Modify the skills section with your own technologies
4. **Projects**: Replace the project cards with your own work
5. **Contact Form**: Update the form submission handler in `script.js` to connect to your backend
6. **Colors**: Customize the color scheme in `styles.css` (CSS variables `--primary` and `--secondary`)
